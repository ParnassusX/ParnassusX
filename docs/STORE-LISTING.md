## Short description (max 132 characters)

Save and restore your window and tab layouts as presets. Adapts to your screens, and every change can be undone.

## Single purpose

Save the arrangement of browser windows and tabs as named presets and restore it later.

## Detailed description

Window Layout Manager saves how your browser is arranged (which windows are open, where they sit, which tabs are in them) and brings it back in one click.

- Save the current layout with a name, and apply it from the toolbar, the side panel or a keyboard shortcut.
- Presets adapt to your screens: if a screen is a different size or is missing, windows are scaled and kept on screen.
- Undo what you did: apply, delete, rename, update, import. Closed windows can be brought back.
- Keep earlier versions of a preset and restore them.
- Start from ready-made layouts for code review, writing, planning, presentations, reading and meetings.
- Search presets by name, tab title or address. Assign the three keyboard shortcuts to the presets you use most.
- Light and dark themes.

Private by design: everything stays on your device. No account, no analytics, no tracking.

## Permission justifications (Privacy practices tab)

| Permission | Why it is needed |
|---|---|
| `windows` | Read the position, size and state of your windows to save them, and open and place windows to restore them. |
| `tabs` | Read the address and title of each tab to save it, and open tabs when a layout is restored. Without it the extension cannot know which pages are open. |
| `storage` | Keep your presets and settings. Presets stay on the device. |
| `system.display` | Read the size and position of your screens so windows can be placed on the right screen and scaled when screens change. |
| `sidePanel` | Show the preset manager in Chrome's side panel. |

## Data disclosures

- The extension handles website content in the sense of tab URLs and titles, and stores them locally only.
- It does not sell data, transfer it to third parties, or use it for anything other than the single purpose above.
