# Privacy policy (draft)

Draft for the owner to review, adapt and host at a public URL. The Chrome Web Store asks for that URL when an item handles user data. It is not legal advice.

**Window Layout Manager** saves the arrangement of your browser windows and tabs so you can restore it later.

## What the extension stores

When you save a layout, it stores on your device:

- the web address (URL) and title of each tab in your open windows;
- each window's position, size and state, and the size and position of your screens.

It also stores your settings (how to apply a layout, screen scaling, theme) and a short history of your own changes so you can undo them.

Tabs that are not web pages (for example `chrome://` pages and local files) are not saved.

## Where it is stored

- Layouts and the change history are stored in the browser's local extension storage, on this device only.
- Settings are stored in Chrome's extension sync storage, which follows your Chrome profile if you have Chrome Sync turned on. Layouts are not stored there.

## What it does not do

- It does not send any data to the developer or to any third party.
- It has no account, no analytics, no advertising and no remote code.
- It does not read the content of web pages.

## Your control

- You can delete any layout from the extension, and you can export all layouts to a file you keep.
- Removing the extension removes its local data.
- If you export a file, it contains your tab URLs and titles. Treat it like your browsing history when you share it.

## Changes

If this policy changes in a way that affects how your data is handled, the change will be described in the store listing and in the extension's release notes.
