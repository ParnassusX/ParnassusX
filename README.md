# Chrome Extension Starter Template

This is a basic starter template for a Chrome Extension (Manifest V3).

## Structure

*   `manifest.json`: The core manifest file. Defines the extension's name, version, permissions, and actions.
*   `popup.html`: The HTML file for the extension's popup window, which appears when you click the extension icon.
*   `style.css`: Basic CSS for the `popup.html`.
*   `popup.js`: JavaScript for the `popup.html`. Contains logic for the popup window.
*   `icon.png`: A placeholder icon for the extension.

## How to Load in Chrome

1.  Open Chrome and navigate to `chrome://extensions`.
2.  Enable "Developer mode" using the toggle switch in the top right corner.
3.  Click the "Load unpacked" button.
4.  Select the directory containing these files.

Your extension should now be loaded and visible in your Chrome toolbar (you might need to pin it from the puzzle-piece extensions menu).
