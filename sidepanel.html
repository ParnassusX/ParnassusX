Keyboard shortcuts

Ctrl+Shift+1, 2 and 3 (Command on Mac) apply the preset assigned to each slot. Assign slots from a preset's menu.

    Download all presets as a JSON file. Keep it as a backup or share it.

    Presets with the same name are replaced. You can undo the import from the Presets tab. Tabs that are not web pages are dropped.
